EVALUATION BENCHMARK · PROPOSAL v0.1

KINE-Bench
消费级世界模型评测基准

让世界模型的"进步"可以被任何人用一张消费级显卡复核。不比谁的视频更好看，比谁真的学到了世界的运行方式。

勘境 KINEWORLD 发起 · 2026-08-30 · 提案公开，征集反馈 · 代码与榜单工具永久 MIT 开源 · 实现进度：v0.3 已发布（五项任务，见 训练报告 与 kine-bench 仓库）· 公开排行榜已上线

为什么需要它 / Why

世界模型赛道当前最大的问题是不可验证：

  • 训练动辄数百张卡，学术界和创业者都无从复现；
  • "成本降低 90%"这类口径没有公开基准，无从核对；
  • 论文指标（FVD 等）衡量生成质量，不衡量"物理规律是否被学到"。
KINE-Bench 的定位：比谁真的学到了世界的运行方式，且全过程单卡可复核。

三条设计原则 / Principles

  1. 消费级优先：每个评测任务必须能在单张 24GB 以下显卡完成推理，训练侧提供"单卡参考实现"。
  2. 物理优先：任务考察因果与物理一致性，而非像素级重建。
  3. 全流程公开：数据集构建脚本、评测代码、排行榜脚本全部开源。

任务集 / Tasks v0.1

任务考察点形式
KINE-PHY-1 落体与反弹重力加速度、恢复系数一致性给前半段视频预测后半段隐空间轨迹，与参考物理模拟做时序相关性
KINE-PHY-2 碰撞传递动量守恒直觉判别扰动样本（违反动量守恒的合成帧）
KINE-CAU-1 干预预测因果而非相关同场景"有/无干预"配对视频，模型对干预后果的区分度
KINE-EMB-1 可供性面向操作的表征抓取可行区域预测与标注 IoU（小规模人工标注集）

每个任务提供：冻结评测集 + 参考随机基线 + 参考单卡模型分数。提交即对比三者。

实现进度说明：v0.3 已先行交付五项可立即复核的任务——KINE-TEMP-1 / MOT-1 / FUT-1 / EVT-1 / EMB-1（具身仿真版，见 训练报告 与 仓库）；上表中的 PHY / CAU / 可供性任务为后续里程碑，EMB-1 仿真探针已率先覆盖"物理模拟中的想象"这一子目标。

提交流程 / Submit

  1. Fork KINE-Bench 仓库；
  2. 本地运行 kinebench eval --task all（评测脚本固定，防止过拟合私有集）；
  3. 提交 results.json + 训练配置 + 硬件说明，PR 即入榜；
  4. 榜单按"单卡赛道 / 不限算力赛道"分列——单卡赛道是主赛道。
