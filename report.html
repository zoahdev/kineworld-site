SETUP

实验配置

架构JEPA（arXiv:2404.08471 思想的 clean-room 自主实现）：ViT-S/16 编码器 + 3D tubelet（2×16×16）+ 时空多块掩码 + EMA 目标编码器 + Transformer 预测器，L1 损失
硬件NVIDIA GeForce RTX 5070 Ti Laptop GPU（12GB）× 1，bf16 混合精度
输入16 帧 × 224×224 视频片段，ImageNet 归一化
数据98 条机器人操作类片段，由 kine-datapipe v0.2 从公开互联网视频端到端产出（下载→切分→运动过滤）
优化AdamW，峰值学习率 3e-4，500 步线性预热 + 余弦衰减，掩码比例 0.90→0.75 余弦退火，EMA 动量 0.996→1.0
规模25000 步，batch 8，每 5000 步存检查点，每 100 步写 metrics.jsonl
代码github.com/zoahdev/kine-jepa（MIT 协议，含实验档案 EXPERIMENT.md）
REPRODUCE

复现方式

同一份代码、同一组超参、同一个种子。任何一台 12GB 以上显存的机器都可以重跑这个实验：

git clone https://github.com/zoahdev/kine-jepa.git
cd kine-jepa
python -m venv .venv
.venv/Scripts/pip install torch torchvision --index-url https://download.pytorch.org/whl/cu128
.venv/Scripts/pip install -r requirements.txt
.venv/Scripts/python -m kineworld_jepa.train --data-dir <clips目录> --steps 25000 --batch-size 8 --seed 42
局限性如实说明：98 条片段的数据规模证明的是管线与工程的可复现性，而非 SOTA 表征质量；评测以 KINE-Bench 基准为准，不做无基准的口头对比。
