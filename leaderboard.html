如何上榜 / Submit

  1. 克隆 kine-bench，用你的检查点运行 python -m kinebench run --ckpt 你的权重 --data-dir 你的数据（评测代码不得修改）；
  2. 提交 PR：results.json + 训练配置 + 硬件说明 + 权重获取方式（公开链接）；
  3. 复核通过后合入并更新本页——PR 即入榜，全程留痕；
  4. 单卡（≤16GB 显存）训练的检查点进入主榜；不限算力条目另列并注明。
数据要求：可以用自己的数据训练，但评测必须使用 KINE-Bench 自带的冻结评测集与固定协议（评测代码 + 数据随仓库分发），防止对私有集过拟合。
