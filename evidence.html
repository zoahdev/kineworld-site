VERIFY IN 10 MINUTES

十分钟验证指南

以下命令在任何一台带 NVIDIA 显卡（甚至只用 CPU）的机器上都能执行。我们不预设你会信任我们，我们预设你会怀疑：

# 1. 官网与证书
curl -I https://kineworld.com

# 2. 克隆代码，跑一次 30 步冒烟训练（任何 GPU 均可）
git clone https://github.com/zoahdev/kine-jepa.git
cd kine-jepa
python -m venv .venv
.venv/Scripts/pip install torch torchvision --index-url https://download.pytorch.org/whl/cu128   # Linux/macOS 用 .venv/bin/pip
.venv/Scripts/pip install -r requirements.txt
.venv/Scripts/python -m kineworld_jepa.train --smoke --steps 30

# 3. 克隆评测基准，复算我们的数字
git clone https://github.com/zoahdev/kine-bench.git
# 完整步骤见 kine-bench/README.md，结果写入 results/*.json 可逐项对照
ASK US ANYTHING

我们主动欢迎这些质疑

"你们能复现吗？"
能。上面就是复现路径。判断任何一家世界模型团队，只需要问这一个问题。
"数字是不是挑好的说？"
不是。低于随机基线的数字（如 KINE-TEMP-1 在早期检查点为 0.500）同样原样发布在报告与仓库里。我们公布失败，因为失败是训练的一部分。
"规模这么小，有什么意义？"
98 条片段证明的是管线与工程的可复现性，不是 SOTA 表征——这句话同样写在报告里。意义在于：当别人还在讲愿景，我们已经在公开地做实验。
"怎么证明比别人强？"
我们不点名比较。把这一页转给任何声称有世界模型的团队，请他们给出同等密度的可查证证据——比较自然会有结果。
HONEST LIMITS

我们还没做到的事

  • 真机部署尚未启动——六个月内公开演示是写进路线图的承诺，未到期，不虚构。
  • 数据规模仍是消费级——单卡实验回答的是"方法可复现"，不是"表征最强"。
  • 尚未完成融资——我们的尽调材料就是这些公开链接本身。
这一页存在的意义：用证据替代承诺，用可复核替代宣称。勘境相信，世界模型这个领域需要的不是更多发布会，而是更多可以被任何人验证的实验。
